About This Project

A college-level data analytics & machine-learning project that discovers products purchased together using association rule mining — and turns those patterns into product recommendations and smart combo offers.

BCA Project Data Analytics Machine Learning

Objective

To analyze retail transaction data and discover hidden relationships between products using association rule mining, then use those relationships to recommend products and build smart promotional combos.

Input — retail transactions (CSV / Excel)
Process — Apriori / FP-Growth finds frequent itemsets & association rules
Output — rules (support · confidence · lift), recommendations & combos

Algorithms

📐
Apriori

Breadth-first search that counts item frequencies and prunes itemsets that can never be frequent (downward closure).

⚡
FP-Growth

Faster alternative that builds an FP-tree and mines frequent itemsets without candidate generation.

🔗
Association Rule Mining

Finds rules of the form Antecedent → Consequent and rates them using Support, Confidence and Lift.

Important Terms

The three measures that drive every analysis in this app
📊
Support

How frequently an itemset appears in all transactions.

Support(A→B) = count(A∪B) ÷ total transactions
🎯
Confidence

How often the consequent is bought when the antecedent is bought.

Confidence(A→B) = support(A∪B) ÷ support(A)
⚖️
Lift

How much stronger the association is than pure random chance.

Lift(A→B) = confidence(A→B) ÷ support(B)
Rule of thumb: Lift > 1 → positive association · Lift = 1 → independent · Lift < 1 → negative association. This app only surfaces genuine (Lift ≥ 1) patterns.
